### Stack

- **Apple platforms** — Swift 6, SwiftUI, AppKit, Vision, PDFKit, Core Location, Foundation Models
- **Web** — TypeScript, Next.js, React, Tailwind CSS, Zustand, Vite
- **Data** — Postgres, Supabase, Prisma, Turso, SQLite, FastAPI, Python
- **Shipping** — Vercel, App Store Connect, Xcode

Use the platform's own frameworks. Keep the number of moving parts low. Model access sits behind a provider abstraction in every project that uses it, so a model can be swapped without touching feature code.
