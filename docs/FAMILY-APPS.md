# Family-only apps

Six apps I run for my own family. They are not public, they are not linked from
anywhere, and nothing they hold is shown on this profile or in this repository.
This page records that they exist, what each is for, and how each is protected,
so the work is documented without being exposed.

| App | What it is for | How it is protected |
|---|---|---|
| **MSRX Study** | Chapter-by-chapter study notes for JEE Maths, Physics and Chemistry. Each chapter has notes, three difficulty levels and past-year questions, written to be read in one sitting. | Access code, kept out of search engines |
| **MSRX PYQ Desk** | Past JEE Main and Advanced papers, cut into single questions and filed by subject, chapter and topic so one topic can be drilled at a time. | Access code, kept out of search engines |
| **MSRX PUC PYQ Desk** | The same idea for Karnataka 2nd PUC board papers: Physics, Chemistry, Mathematics, Computer Science and Hindi, filed by chapter. | Access code, kept out of search engines |
| **JR IIT Library** | A sorted shelf of the study material shared inside one coaching batch, by subject and chapter, so it can be found again. Files are kept exactly as received. Results, marks, ranks, attendance and photos of students are never published to it. | Access code, kept out of search engines |
| **Family Results Room** | A private page that tracks one student's weekly test results over time. | Password only; passwords are stored as hashes |
| **MSRX Usage Dashboard** | An owner-only view of how much load every site puts on its free hosting plan, by day, week and month, so none is surprised by a limit. | Password only |

## Ground rules

- **No content here.** No screenshots, no data, no question papers, no names of
  students and no web addresses of the pages that hold private data.
- **Not for sharing.** If you have somehow reached one of these, please close
  it. They hold material that belongs to the people they were made for.
- **Same standards as the public apps.** No ads, no tracking, nothing sold.
  The code lives in private repositories.
